# StockExpert

Автор и создатель проекта: **ganievshr**.

Версия: **3.9.13-b1.2**, исправленный запуск контейнеров (launcher revision 2).

Исходный код FastAPI/Celery и React/Vite, режимы shared/split, загрузка списка
потребностей из TXT, десять параллельных запросов и CPU/CUDA reranker.

- [История изменений](CHANGELOG.md)
- [Как обновить GitHub с сохранением коммитов](docs/GIT_UPDATE_RU.txt)
- [Описание B1 и запуск](README_B1.md)
- [Параллельный CPU/GPU-режим](docs/B1_PARALLEL_GPU_RU.md)

В комплект не входят рабочая БД, Docker volumes, резервные копии, полный ЕБДЗ,
генерируемый каталог на 12 000 строк и старые выгрузки результатов экспериментов.
Схема БД, миграции, тесты и небольшие тестовые эталоны оставлены.
Скрипты запуска сами создают необходимые хранилища при развёртывании.

Исторические `docs/CHANGESET_*.json` описывают исходные выпуски; актуальные
контрольные суммы комплекта находятся в `MANIFEST_B1.sha256` и манифестах
двух компонентов. Проверки текущей упаковки: `docs/PACKAGE_VALIDATION.json`.
