# StockExpert 3.9.11 — исправление Unknown mapped column

Ошибка возникала при подготовке Excel: Qwen возвращала содержимое ячеек вместо номеров столбцов в name_columns. Например, «Арматура промышленная трубопроводная» не является идентификатором столбца. Для двухколоночного листа допустимы 0/1 либо A/B.

## Исправление бэкенда

- app/services/column_mapping.py: JSON Schema ограничивает ответ реальными номерами и буквами столбцов; проверяются повторения и наличие строк после заголовка. При некорректном ответе выполняется один повтор с диагностикой и допустимыми идентификаторами.
- app/services/workflow.py: единая проверка столбцов для подготовки и ручного редактирования; при двух неудачных ответах модельной разметки используется детерминированное определение столбцов с обязательным подтверждением пользователя.
- Ошибки сервера модели, подключения, авторизации и отмена задания продолжают обрабатываться как ошибки/отмена; они не маскируются резервной разметкой.
- Решение и диагностика сохраняются в job.params.column_mapping и событии SCHEMA_PROPOSED. Подготовка останавливается в REVIEW_REQUIRED, mapping_approved=false.
- Резервное определение столбцов не меняет метод H1: выбранная Qwen выполняет извлечение характеристик после утверждения столбцов. H2 по-прежнему независимо отключается для всех методов.

Правила извлечения H1, эталоны и результаты прошлых экспериментов не изменены. Новых миграций относительно 3.9.10 нет. Проверка существования столбцов не отключена.

## Восстановление вашей сессии

1. Установите обновление и нажмите «Повторить задачу» в неудачной сессии подготовки. Удалять сессию или заново загружать ЕБДЗ не требуется.
2. Для прежнего файла ЕБДЗ на 100 позиций проверьте: лист «Лист1»; строка заголовков **0**; описание **A, B**; категория — пусто. Первая строка с арматурой является товаром, а не заголовком.
3. Нажмите «Утвердить столбцы», затем отдельный H1 или полный запуск. Qwen Q4 остаётся выбранной моделью.

Для сравнения с уже посчитанными экспериментами сохраните A и B: там на вход передавались оба столбца. Если решите использовать только описание B, это отдельный протокол; одинаково повторите регулярки и LLM.

При резервной разметке незнакомого листа без заголовков сохраняются все строки и до 10 столбцов. Если столбцов больше 10 и распознать заголовок не удалось, потребуется файл с явными заголовками «Описание»/«Наименование»; программа не обрезает лишние столбцы молча.

## Обновление в WSL

Сохраните архив в C:\Users\ganie\Downloads и выполните в Ubuntu:

```bash
mkdir -p /home/ganie/StockExpert3.9.11 &&
unzip -o /mnt/c/Users/ganie/Downloads/StockExpert_3.9.11_mapping_fix.zip -d /home/ganie/StockExpert3.9.11 &&
cd /home/ganie/StockExpert3.9.11 &&
bash install_update.sh
```

Скрипт переносит прежний .env, использует проект stockexpert-backend и прежние Docker-тома, сохраняет резервную копию PostgreSQL и проверяет историю до/после обновления. При активных заданиях обновление останавливается. Не удаляйте Docker-тома. Если .env не найден, скопируйте прежний в stockexpert-backend/.env и повторите команду bash install_update.sh.

Интерфейс: http://localhost:5173. В архив включены backend, frontend и прежние материалы версии 3.9.10.

## Проверка

Полный набор: 283 backend-теста прошли. Сборка frontend прошла. На исходном EBDZ_100.xlsx отдельно проверены резервная разметка A/B без заголовка и сохранение всех 100 позиций.

Тесты воспроизводят передачу названий групп в name_columns, ошибочный JSON, неверную категорию, повтор столбца, неверный заголовок, сбои модели, все пять профилей LLM, обязательное подтверждение разметки и повтор старого задания с сохранением идентификаторов всех 100 строк. Вызовы модели заменяются контролируемыми ответами; реальная Qwen на компьютере пользователя в этой проверке не запускалась.
