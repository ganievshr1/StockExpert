Эталон H1 по 99 текстам МТР (из версии 3.9.7, включён в 3.9.8)

Состав эталона expert_reference_H1_text_99.json:
99 описаний из столбца C, строки 1–99 листа Лист1 исходного Excel.
Включено изделие в первой строке. Повторяющиеся описания разных строк
сохранены как отдельные позиции. Категории H2, организация, отдельные
характеристики и потребности опросного листа не участвуют в H1.
Исходные ячейки A/B/C сохранены только для проверки привязки к файлу.

Правило: одна строка = один текст name. Сравниваются все символы после
удаления пробелов по краям; регистр и внутренние пробелы сохраняются.
TP — текст совпал; FP — выдан несовпавший текст; FN — правильный текст
пропущен или заменён другим. Precision=TP/(TP+FP); Recall=TP/99;
F1=2TP/(2TP+FP+FN). Число эталонных объектов всегда 99, а не количество
параметров и не сумма паспортов остатков и опросного листа.
F1 текста отличается от прежнего micro-F1 технических параметров.

Обновление и новая выгрузка: см. README_EXPORTS_3.9.8.txt.

После обновления:
1. Откройте http://localhost:5173 и обновите страницу Ctrl+F5.
2. «Для разработчика» → «Загрузить эталон» → expert_reference_H1_text_99.json.
3. Выберите сессии с исходной базой, пересчитайте метрики.
4. В автоматическом дашборде выберите «H1 — 99 описаний МТР, только текст».
5. Для ручной проверки используйте режим «H1 · Только текст».
   По умолчанию показываются только остатки Excel. H2 проверяется отдельно.

Прежние эталоны и сохранённые оценки не удалены. В старом запуске без
паспорта первой строки эта позиция считается пропущенной; результат
не превращается в 100% за счёт её исключения. Для исправления самого
предсказания нужен новый запуск обработки, а не редактирование истории.
При неполной ручной разметке метрики относятся только к проверенным
текстам; покрытие показывается отдельно. Непроверенные тексты не
приравниваются к ошибочным. Автоматическое сравнение охватывает все 99.

H2 и H3 не включены в этот отдельный файл. Используйте для них прежний
эталон или отдельную разметку. Статус READY для нового эталона означает
готовность H1, а не успешную проверку всех трёх гипотез.
Тексты скопированы из Excel без интерпретации. Независимая экспертная
проверка не заявляется. Результаты моделей не подставлены в эталон.

Проверка поставки: тесты расчёта, совместимости старых метрик,
разделения источников и интерфейса; сборка TypeScript/Vite.
Развёртывание на компьютере пользователя здесь не выполнялось.
