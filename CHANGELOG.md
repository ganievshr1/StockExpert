# История изменений StockExpert

Автор проекта: **ganievshr**.

## 31.10.2026 — 3.9.12: лаборатория H1/H2/H3

- Базовая версия backend/frontend до B1.
- Загрузка экспертной разметки H2, фиксированное дерево категорий и train/test.
- Сравнение пяти подходов: TF-IDF/k-means, векторизация/HDBSCAN и LLM.
- Accuracy L3, дополнительные метрики и отдельный отчёт H2.
- Сохранены регулярные выражения, нормализация, поиск и лаборатория H3.

## 07.11.2026 — 3.9.13-b1 / b1.1: очереди и список потребностей

- Общая очередь shared и раздельные interactive/batch, профили workers.
- Состояние заданий, маршрутизация и telemetry, API и контроллер экспериментов B1.
- Панель React, CLI нагрузки, сценарии нескольких пользователей и последовательной серии.
- Явный режим TXT «одна строка = одна позиция», подсчёт позиций до загрузки,
  несколько файлов потребности и пример десяти строк.
- Тесты API, очередей, конкурентной обработки и загрузки потребностей.

## 07.11.2026 — 3.9.13-b1.2: параллельные запросы и CPU/CUDA

- Сценарий «один пользователь × десять одновременных запросов».
- Пул потоков worker с ограниченным числом слотов, настройки ожидания и прогресса.
- CPU/CUDA/auto для CrossEncoder, одна модель, ограничение конкурентного inference,
  уменьшение batch при нехватке VRAM и предусмотренный переход на CPU.
- Профили Compose и отдельный launcher, тесты API/runner/reranker/frontend.

## 07.11.2026 — launcher revision 2

- Закреплены Docker projects `stockexpert-backend` и `stockexpert-frontend`.
- Поиск остановленного frontend по labels, чтение объявленного порта.
- Проверка сети backend/инфраструктуры, обработка дубликата frontend.
- Расширены тесты запуска; прикладной backend/frontend-код не изменён.

## 09.11.2026 — комплект для GitHub

- Рабочие БД, резервные копии и полные каталоги не включаются в снимки.
  Исключены также генерируемые результаты и старые журналы; оставлены
  миграции, схема, тесты и небольшие тестовые эталоны.
- Добавлены правила `.gitignore`, инструкция и скрипт полного обновления
  дерева GitHub с объединением двух историй через merge-коммит.
- Добавлены пять проверок скрипта, актуальные SHA-256-манифесты, bundle
  и текстовый экспорт истории в поставляемом архиве.
