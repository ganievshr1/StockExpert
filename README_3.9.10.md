# StockExpert 3.9.10 — отключаемая таксономия H2

Таксономия — отдельный выбор для регулярок и всех профилей LLM. В новой сессии H2 выключен по умолчанию; выбор модели не меняет эту настройку.

## Как использовать

1. Создайте новую сессию. В блоке «Режим H2 — таксономия» выберите «Без H2 — сразу к поиску» либо «С H2 — построить категории».
2. Выберите регулярки или LLM для H1. Переключатель H2 доступен для Qwen2.5 7B Q4/Q5, Qwen3 8B, Qwen2.5 14B и DeepSeek одинаково.
3. Кнопка отдельного H1 выполняет извлечение. При включённом H2 новый расчёт останавливается в H1_READY: категории запускаются отдельной кнопкой H2. Полный запуск проходит H1 → H2 → H3 с утверждением дерева, когда H2 включён, либо H1 → H3 без дерева, когда выключен.
4. После начала обработки настройка фиксируется, чтобы не менять смысл сохранённых результатов. Для сравнения режимов создайте отдельные сессии с одинаковым Excel. Для нового опыта H1 загрузите Excel заново: готовая база переиспользует уже извлечённые паспорта.

При выключенном H2 категории не строятся, подтверждение дерева не требуется, сервер отклоняет отдельный запуск H2. Кабельные правила H1 продолжают работать. Поиск H3 может использовать эмбеддинги и ранжирование; отключение H2 отключает именно таксономию.

Вкладки ручной и автоматической проверки, отдельные оценки H1/H2/H3, экспорт и история расчётов версии 3.9.9 сохранены. Для прежних сессий режим не переключается миграцией. В новых экспортах режима без H2 этап отмечается skipped, а не нулевым качеством классификации.

## Обновление в Ubuntu / WSL

Распакуйте архив в отдельную папку, откройте её и выполните:

```bash
bash install_update.sh
```

Скрипт использует прежние Docker-тома и настройки, делает резервную копию PostgreSQL, останавливается при активных заданиях и проверяет количество записей до и после миграции. Миграция 0011 меняет только значение H2 по умолчанию для новых записей. Если старый .env не найден, скопируйте его в stockexpert-backend/.env и повторите запуск. Интерфейс: http://localhost:5173.

## Проверка

263 backend-теста, 53 frontend-теста и production-сборка frontend прошли. Проверены включение/выключение H2, H1 и полный запуск для всех пяти профилей LLM и регулярок, экспорт и сохранение старых режимов/снимков при миграции. Вызовы LLM в автотестах заменены контролируемыми ответами: реальные модели на вашем компьютере не запускались. Docker-развёртывание на вашей машине в эту проверку не входит.

Дополнительные инструкции по оценке и эталону находятся в README_3.9.9.md.
