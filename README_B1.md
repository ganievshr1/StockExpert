# StockExpert B1 — 3.9.13-b1.2

В версии 3.9.13-b1.2 добавлены один пользователь с десятью одновременными
запросами, диагностика с настраиваемым лимитом ожидания, корректное отображение
прогресса и отдельный профиль CPU/CUDA. Инструкция с сохранением данных:
[docs/B1_PARALLEL_GPU_RU.md](docs/B1_PARALLEL_GPU_RU.md).
Профиль parallel предназначен для диагностики; подтверждающая B1 требует
одинакового вычислительного бюджета сравниваемых вариантов.

Полный исходный проект с переключаемыми очередями `shared` и `split`, сервисным разделом проверки B1 и отдельной имитационной моделью.

Новый стенд по умолчанию использует отдельные Docker project и сеть, интерфейс на `http://localhost:5175`, API на `http://localhost:8002`.

```bash
bash b1.sh init
bash b1.sh start shared
bash b1.sh models
```

Данные администратора находятся в созданном `stockexpert-backend/.env`. Для Docker без NVIDIA используйте CPU-инструкцию. Короткие серии на 10 запросов служат диагностикой; подтверждение B1 требует пяти парных прогонов полного протокола с одинаковыми ресурсами и фоновой подготовкой каталога. Имитационные результаты не являются измерениями производительности приложения.

Для исходного релиза 3.9.13-b1 было проверено: 375 backend-тестов, 64 frontend-теста, production-сборка, 3 проверки запуска и 11 проверок симулятора. Реальный Docker/GPU эксперимент здесь не выполнялся. Модельный тяжёлый профиль не подтвердил снижение p95 на 30%.

В 3.9.13-b1.1 добавлены явный режим TXT «одна строка = одна позиция», предварительный подсчёт позиций и загрузка нескольких файлов потребностей. Результаты проверок этого исправления находятся в `docs/B1_POSITIONS_VALIDATION.json`.
