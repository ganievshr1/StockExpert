# Проверка StockExpert 3.9.5

Дата: 17 октября 2026. Основной движок H1: регулярные выражения вместо генеративной модели.

## Результаты проверок

- Бэкенд: **208 passed**. Предупреждение зависимостей TestClient — deprecated alias AnyIO, без ошибки выполнения.
- Фронтенд: **35 passed**, 7 файлов тестов. Production-сборка TypeScript/Vite успешна.
- Основная сессия: создание с выбором H1, загрузка XLSX/TXT, определение столбцов и подтверждение, H1 без LLM, сохранение паспортов в `items`, оценка H1 через общий расчёт метрик.
- Последовательность H1→H2→H3: реальная логика построения таксономии и подбора; модель H2 возвращает контролируемые тестовые ответы, векторное хранилище Qdrant работает в памяти. Проверены сохранение `provider=regex` и исходных характеристик, классификация обозначений с нерасшифрованными кодами, схема единиц A/kW/Hz и размеров строкой.
- Старые LLM-сценарии проходят прежние тесты. Выбор метода не изменяет паспорта готовой базы. Исторические сессии и задания остаются LLM.
- Миграции заполненных баз 0006→0009, 0007→0009 и 0008→0009 проверены повторно, прежние значения всех колонок сравниваются целиком, проверяются внешние ключи и индексы. Новое поле у старых сессий — `llm`.
- Проверены ограничения ролей и организаций, запрет смены H1 после старта, независимый выбор H2 после H1, снимок метода при повторе задания и отказ при изменении хеша правил/адаптера.

## Ограничения

Применялась временная SQLite; Redis и MinIO заменены тестовыми реализациями. Реальный Docker/PostgreSQL на компьютере пользователя и качество живой модели H2 не проверялись. Автоматизация интерфейса — component-тесты, без визуальной проверки в настоящем браузере.

Входной Excel использован при адаптации правил. Его охват не является точностью; без экспертного эталона F1 не рассчитывается. После отдельного H1 метрики H2/H3 пусты. Неоднозначные коды/размеры требуют проверки. Многострочный опросный лист в режиме регулярных выражений сохраняется одной позицией с замечанием.
