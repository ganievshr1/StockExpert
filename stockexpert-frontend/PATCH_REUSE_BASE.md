# StockExpert 3.9.0 — готовая база и открытый раздел разработчика

Исправление от 12 октября 2026 года. Автор проекта: ganievshr.

## Готовая база

В новой сессии выберите «Использовать готовую базу», укажите ранее нормализованную базу, загрузите только новый опросный лист и нажмите «Сопоставить с готовой базой».

- Нормализованные значения, категории, правила сравнения и сведения об исходной модели сохраняются независимо от модели новой сессии. Складские паспорта повторно не извлекаются и не классифицируются.
- Выбранная модель обрабатывает только новый опросный лист и сопоставляет его признаки с готовым классификатором. Её можно изменить до первого запуска новой сессии.
- Если опросный лист уже обработан, основная кнопка запуска создаёт задачу только сопоставления. Проверка доступности генеративной LLM и её повторный вызов не требуются.
- Существующие векторы переиспользуются при совпадении модели эмбеддингов и текста. Если векторов нет или модель эмбеддингов изменилась, пересоздаются только векторы; нормализация базы не запускается.
- Использованные и очищенные позиции не возвращаются в доступный склад. История исходной сессии сохраняется.
- Для отдельного эксперимента с повторной нормализацией другой моделью создайте сессию с новым Excel. Выбор готовой базы означает использование готовых результатов.

Ранее созданные сессии с признаком `reused_passports=false` автоматически не переделываются: это могло бы изменить сохранённый эксперимент. Для нового подбора создайте сессию, выбрав исходную готовую базу. Загружать и нормализовывать её снова не нужно.

## Раздел разработчика

«Для разработчика» расположен непосредственно в основной навигации администратора. Раскрывать «Настройки» не нужно. Действующие серверные права администратора сохранены. Раздел содержит загрузку экспертного эталона, выбор сохранённых сессий, расчёт и выгрузку сравнительных метрик.

## Обновление установленной версии в WSL

Сохраните прежние `.env` и Docker-тома. Завершите активные задания перед обновлением. Для установленного проекта в `/home/ganie/StockExpert3.9.0` распакуйте оба обновлённых архива в эту папку с заменой файлов. Корневая структура архивов сохранена: `stockexpert-backend/` и `stockexpert-frontend/`.

Затем выполните:

```bash
cd /home/ganie/StockExpert3.9.0/stockexpert-backend && bash scripts/upgrade_preserve_data.sh && cd ../stockexpert-frontend && docker compose -p stockexpert-frontend up -d --build
```

Скрипт backend по умолчанию использует прежнее имя проекта `stockexpert-backend`, делает резервную копию PostgreSQL и `.env`, обновляет приложение. Redis, MinIO, Qdrant и Ollama должны быть запущены; подробности — в `UPDATE_3.9.0.md`. Новых миграций в этом исправлении нет. Не запускайте `down -v`, `volume prune` или `reset_stack.py`.

После обновления откройте приложение и нажмите Ctrl+F5.
