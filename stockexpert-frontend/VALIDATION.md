# Проверка удаления сессий — 2 октября 2026

- Бэкэнд: 103 теста проходят, включая 12 новых проверок одиночного/массового удаления. В новых тестах SQLite включает проверку внешних ключей.
- Проверены удаление графа зависимостей, права и изоляция организаций, блокировка активных заданий, сбои MinIO/Qdrant и повтор, частичный массовый результат, удаление за пределами страницы, независимость скопированной базы, сохранение `USED` и удаление неиспользуемых складских записей без ссылок.
- Фронтэнд: TypeScript/Vite production build проходит; 17 тестов проходят, включая 8 новых сценариев подтверждения, отмены, фильтра/пагинации, сброса выбранной сессии, частичного сбоя и прав.
- Playwright/Chromium с настоящим локальным API: 1440×960 (светлая тема) и 390×844 (тёмная). Проверены отмена удаления, удаление последней строки на второй странице, удаление открытой сессии из вложенного окна управления, восстановление прокрутки и массовое удаление при активном поисковом фильтре. Ошибок JavaScript/HTTP в этих сценариях не было.
- Дополнительно исправлено повторное открытие уже выбранной сессии: загруженные данные больше не сбрасываются без повторного запроса. Вложенные окна корректно освобождают блокировку прокрутки.
- OpenAPI обновлён в обоих проектах. В архив бэкэнда включена локальная сборка MinIO, ранее применённая при развёртывании.

Ограничения: новые проверки выполнялись с SQLite, Qdrant в памяти и тестовыми внешними сервисами. Полный Docker Compose и конкурентное выполнение на PostgreSQL в этой среде не запускались. Dockerfile MinIO здесь не собирался. Физические мобильные устройства не использовались.

# Проверка адаптивного обновления · 2 октября 2026

- Production-сборка и проверка TypeScript: `npm run build`.
- Существующие тесты бизнес-интерфейса: `npm test`, 9 из 9.
- Playwright / Chromium 134: 308 проверок размеров в светлой и тёмной темах. Ширины: 320, 360, 390, 600, 768, 900, 901, 1024, 1280, 1440, 1920, 2560 px; отдельно альбомная ориентация 844×390.

- На экране 320×568 таблица кандидатов прокручивалась по обеим осям (содержимое 640×901 px в области 256×367 px); закрепление заголовков и прокрутка стрелкой вправо проверены в браузере.
- При размере 1024×400 боковое меню прокручивается до кнопки выхода (805 px содержимого в 400 px области).
- Диалог новой сессии проверен на 320×568, 390×360, 844×390 и 1440×400: помещается в окно, длинное содержимое прокручивается до кнопки отправки. После закрытия восстанавливается прокрутка основной страницы.
- Мобильное меню прокручивается к выбранному пункту; выход из аккаунта с телефона проверен.
- В мобильной эмуляции 390×844 пройдены: вход с запоминанием, сохранение закупочного решения, подтверждение использования запаса, скачивание XLSX (16 018 байт), PDF-предпросмотр, создание новой сессии, загрузка Excel и TXT, предпросмотр Excel, замена TXT.

Проверки выполнялись с изолированным тестовым FastAPI, временной SQLite и синтетическими данными. Работающее задание для экрана обработки имитировалось ответом тестового API. Реальные модели не загружались, запросы к платным LLM не выполнялись. Физические устройства и Safari/Firefox отдельно не проверялись; браузерная эмуляция не заменяет проверку на конкретном телефоне. Внешний вид и автоскрытие системных полос прокрутки зависят от ОС и браузера.

Далее сохранён протокол первоначальной версии 3.7.0.

# Проверка версии 3.7.0

Дата: 1 октября 2026. Среда проверки: Linux, Node.js 24.19, Python 3.12. Production Dockerfiles используют Node.js 22 и Python 3.11.

## Выполнено

- Восстановлены проекты из двух последних присланных текстовых дампов. Статические демонстрационные числа из Figma не подставляются вместо результатов API.
- Сопоставлены 16 состояний интерфейса в каждой теме: вход, рабочий стол, обзор сессии, загрузка, классификатор, подбор, экспертное решение, отчёт, обе формы проверки качества, аудит, метрики, новая сессия, обработка, рекомендация и использование.
- `npm run build`: проверка TypeScript и production-сборка Vite проходят.
- `npm run test`: **9 тестов** проходят. Проверяются утверждение столбцов отдельно от классификатора, поступление асинхронной схемы, правила материала, сохранение несохранённых правок при обновлении, блокировка утверждённой схемы, явное подтверждение параметров/категорий, `null`, пропуск неопределённой пары и завершение проверки.
- `python -m pytest -q`: **91 тест** проходит. Включены исходные 81 тест и 10 новых проверок расширения 3.7. Проверяются полный конвейер, качество, повторное использование базы, общий склад, модельные профили, отмена и восстановление, изоляция организаций, замена источника, кодировки TXT, фильтры аудита/очереди, добавление признаков и отчётные разделы.
- OpenAPI получен из работающего приложения: версия 3.7.0, 70 путей. Один и тот же файл включён в оба архива.
- 47 SVG экспортированы из исходных слоёв Figma без изменения геометрии. XML проверен, исходный размер 24×24 сохранён. В исполняемом коде нет временных URL Figma. Inter включается локально из npm-зависимости.
- Playwright/Chromium: проверены вход, переходы по разделам, обе темы, сохранение оценки паспорта и кандидата, завершение проверки, отображение метрик. На экранах шириной 390 px нет горизонтального переполнения страницы; широкие таблицы и навигация прокручиваются внутри своих блоков. Ошибок JavaScript и HTTP в завершённом проходе не было.
- В дополнительном браузерном сценарии пройдены: сохранённый вход, закупочное решение, подтверждение использования, скачивание XLSX (проверен непустой файл), открытие PDF-предпросмотра, создание сессии с Qwen3, загрузка Excel и TXT, просмотр Excel, замена TXT. Ошибок HTTP и JavaScript нет.
- Статическая проверка изменённых серверных модулей на неиспользуемые/неопределённые имена проходит. Обе части отформатированы; исходные бизнес-модули вне изменённой области сохранены.

## Границы проверки

В тестах внешний генератор, эмбеддинги, Redis и объектное хранилище заменяются управляемыми тестовыми реализациями; Qdrant используется в памяти. Браузер обращался к настоящему локальному FastAPI с временной SQLite БД и синтетическими данными. Эти подмены и тестовый пользователь не подключены к production-коду.

Полный Docker Compose с PostgreSQL/MinIO/Redis/Ollama и настоящими весами моделей в этой среде не запускался. Платные запросы DeepSeek не выполнялись. Скорость на вашем оборудовании и качество модели на ваших Excel/TXT не измерялись. Перед рабочим использованием выполните пробную сессию на ваших обезличенных данных и проверьте метрики после разметки.

Не заявляется пиксельное равенство экранов с разным объёмом данных: сохранены палитры, шрифты, основные размеры и компоновка макетов; таблицы, состояния загрузки и ограничения отражают реальную модель данных. В макете демонстрационные числа заменены фактическими результатами. Количество частичного списания, денежный эффект, цифровая подпись и рабочая интеграция с СЭД не добавлены.
