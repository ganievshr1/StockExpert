# Проверка StockExpert 3.9.3

Дата: 17 октября 2026. Основа: пользовательский архив StockExpert3.9.1.

- Бэкенд: `python -m pytest -q` — **181 passed**, 32,88 с. Единственное предупреждение — устаревший alias AnyIO внутри Starlette TestClient.
- Фронтенд: `npm test` — **29 passed**, 7 файлов тестов.
- Production: `npm run build` — TypeScript и Vite успешно.
- OpenAPI пересобран из приложения 3.9.3 и синхронизирован с фронтендом.
- Проверены синтаксис обоих bash-скриптов, YAML Compose, сохранение имён шести прежних томов и независимость `worker-regex` от Ollama/GPU.
- Миграционный тест создаёт заполненную базу 0006, включая 99 позиций, 98 результатов подбора, экспертную оценку, аудит и учётные записи; после повторяемого upgrade до 0007 сравнивает все записи каждой прежней таблицы без изменений.
- Интеграционный тест запрещает обращения к LLM, конфигурации модели и preflight; запускает эксперимент и проверяет неизменность исходных сессий/документов/паспортов/заданий/матчинга/оценок.
- Проверены сохранение снимка после изменения источника, одна запись на ключ запроса, отсутствие повторной перезаписи результата, изоляция организаций и ролей, CPU-очередь, точные формулы H1, отличия полноты строк от micro-F1, экспорты.
- Проверены составные кабели и трубы, явные единицы, сокращения электродвигателя, отсутствие комплектации, противоречия, диапазоны и неизвестные описания.

Границы проверки: использованы изолированные тестовые данные и SQLite. Контейнерный Docker-стек и PostgreSQL пользователя не запускались. Среда не содержала Chromium для визуального скриншота; фронтенд проверен сборкой и DOM-тестами. Значения качества фикстур не являются метриками рабочего эксперимента.
